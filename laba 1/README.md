## 1. Цель работы

Разработать статическую клиентскую часть веб-приложения с использованием HTML и CSS: создать семантическую структуру страницы, оформить интерфейс с помощью Flexbox и CSS Grid и реализовать адаптивную вёрстку.

## 2. Постановка задачи

Создать главную страницу каталога «Мир настольных игр». Каталог предназначен для пользователей, которые выбирают настольную игру для компании, семейного вечера или встречи с друзьями.

На странице необходимо разместить:

- шапку с названием и навигацией;
- главный информационный блок;
- популярные игры;
- форму поиска по названию и выбора жанра;
- каталог из шести карточек игр;
- раздел «О проекте»;
- подвал страницы.

На данном этапе приложение является статическим: JavaScript, серверная часть и база данных не используются. Форма представляет внешний вид будущего поиска.

## 3. Структура проекта

Основные файлы проекта:

| Файл | Назначение |
| --- | --- |
| `index.html` | Структура и содержимое страницы |
| `styles/main.css` | Оформление, сетки и медиазапросы |
| `README.md` | Отчёт о лабораторной работе и инструкция по запуску |
| `screenshots/` | Семь скриншотов интерфейса для отчёта |

CSS вынесен в отдельный файл, который подключается в HTML-документе:

```html
<link rel="stylesheet" href="styles/main.css">
```

## 4. Описание интерфейса

### 4.1. Шапка и навигация

В шапке расположены название «Мир настольных игр» и меню с пунктами «Главная», «Популярное», «Каталог», «Поиск», «О проекте». Ссылки ведут к соответствующим разделам текущей страницы.

### 4.2. Главный блок

Главный блок содержит заголовок «Найди настольную игру для хорошего вечера», описание каталога и ссылку «Посмотреть каталог», оформленную как кнопка. Она позволяет перейти к карточкам игр.

### 4.3. Популярные игры

В разделе представлены три игры: «Каркассон», «Колонизаторы» и Ticket to Ride. Карточки содержат основные характеристики игр и располагаются в сетке.

### 4.4. Форма поиска

Форма содержит текстовое поле для названия игры, выпадающий список жанров и кнопку «Найти». Для полей используются подписи `label`.

Реальный поиск и фильтрация в данной версии не реализованы. Для этого на следующих этапах потребуется добавить программную логику.

### 4.5. Каталог

В каталоге представлены шесть игр:

1. Каркассон.
2. Колонизаторы.
3. Клуэдо.
4. Монополия.
5. Имаджинариум.
6. Ticket to Ride.

Каждая карточка содержит название, жанр, краткое описание, количество игроков и продолжительность партии.

### 4.6. Раздел «О проекте» и подвал

В разделе «О проекте» объясняется назначение каталога и возможность его дальнейшего развития. В подвале размещены название проекта и информация о его учебном назначении.

## 5. HTML-структура

Для разделения страницы на смысловые области используются семантические элементы HTML.

| Элемент | Применение |
| --- | --- |
| `header` | Шапка страницы |
| `nav` | Навигационное меню |
| `main` | Основное содержимое |
| `section` | Тематические разделы |
| `article` | Отдельная карточка игры |
| `form` | Форма поиска |
| `label` | Подпись поля формы |
| `input` | Ввод названия игры |
| `select` | Выбор жанра |
| `button` | Кнопка поиска |
| `footer` | Подвал страницы |

Пример разметки карточки:

```html
<article class="card">
    <div class="card-cover">
        <span>Стратегия</span>
    </div>

    <div class="card-content">
        <h3>Каркассон</h3>
        <p>
            Стратегическая игра о строительстве
            средневековой местности.
        </p>
        <ul>
            <li><strong>Жанр:</strong> стратегия</li>
            <li><strong>Игроки:</strong> 2–5</li>
            <li><strong>Время:</strong> 30–45 минут</li>
        </ul>
    </div>
</article>
```

Элемент `article` выбран потому, что карточка представляет самостоятельный объект каталога.

## 6. Оформление страницы

Оформление находится в файле `styles/main.css`. В интерфейсе используются тёмно-зелёные, светло-зелёные и бежевые оттенки. Отступы разделяют смысловые блоки, а скругления, фоны и единое оформление карточек объединяют элементы страницы.

### 6.1. CSS Grid

Для каталога используется CSS Grid:

```css
.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 25px;
}
```

Свойство `grid-template-columns` создаёт три колонки одинаковой ширины. Свойство `gap` задаёт расстояние между карточками. Grid удобен для размещения элементов по строкам и столбцам.

### 6.2. Flexbox

Навигация оформлена с помощью Flexbox:

```css
.navigation {
    display: flex;
    justify-content: center;
    flex-wrap: wrap;
    gap: 30px;
}
```

Пункты меню выравниваются по центру и при недостатке места переносятся на следующую строку. Flexbox также используется для формы поиска и блока «О проекте».

## 7. Адаптивная вёрстка

Для изменения расположения элементов при уменьшении ширины экрана используются медиазапросы.

Стили для экранов шириной до 900 пикселей включительно:

```css
@media (max-width: 900px) {
    .popular-grid,
    .cards {
        grid-template-columns: repeat(2, 1fr);
    }

    .search-form {
        flex-wrap: wrap;
    }

    .form-group {
        min-width: 250px;
    }

    .about-content {
        flex-direction: column;
        gap: 20px;
    }
}
```

Стили для экранов шириной до 600 пикселей включительно:

```css
@media (max-width: 600px) {
    .navigation {
        gap: 15px;
    }

    .hero {
        padding: 65px 0;
    }

    .hero h1 {
        font-size: 34px;
    }

    .hero-text {
        font-size: 17px;
    }

    .popular-grid,
    .cards {
        grid-template-columns: 1fr;
    }

    .search-form {
        flex-direction: column;
        align-items: stretch;
    }

    .form-group {
        width: 100%;
        min-width: 0;
    }

    button {
        width: 100%;
    }

    .section {
        padding: 55px 0;
    }
}
```

Предусмотренное расположение карточек:

| Ширина экрана | Количество колонок |
| --- | --- |
| Более 900 px | 3 |
| От 601 до 900 px | 2 |
| До 600 px включительно | 1 |

На небольших экранах форма располагается вертикально, уменьшаются размеры заголовка и отступы.

## 8. Управление с клавиатуры

Для интерактивных элементов предусмотрено видимое состояние фокуса:

```css
a:focus,
input:focus,
select:focus,
button:focus {
    outline: 3px solid #d5aa4e;
    outline-offset: 3px;
}
```

При переходе между элементами клавишей `Tab` вокруг текущего элемента появляется рамка. Она помогает пользователю понять, какая ссылка, кнопка или поле сейчас получает ввод с клавиатуры.

## 10. Запуск проекта

1. Скачать репозиторий и при необходимости распаковать архив.
2. Открыть папку проекта.
3. Открыть файл `index.html` в браузере.

Установка зависимостей и запуск серверной части не требуются.

## 11. Проверка страницы

Для проверки результата необходимо:

- открыть страницу при ширине 1280, 768 и 360 пикселей;
- проверить изменение количества колонок каталога;
- убедиться, что текст и поля формы не выходят за границы экрана;
- проверить переходы по пунктам навигации;
- пройти по ссылкам и полям с помощью клавиши `Tab` и проверить видимость фокуса;
- убедиться, что файл CSS загружается и применяется к странице.

## 12. Результат работы

Разработана статическая клиентская часть каталога «Мир настольных игр». Страница включает навигацию, главный блок, популярные игры, форму поиска, каталог из шести карточек, раздел «О проекте» и подвал.

Для структуры использован HTML, для оформления — CSS. Расположение элементов выполнено с помощью Grid и Flexbox. Медиазапросы задают адаптивное расположение карточек и формы.

## 13. Заключение

В ходе лабораторной работы были освоены основы создания статических веб-страниц, использование семантических HTML-элементов и вынесение стилей в отдельный файл. Применены CSS Grid, Flexbox, медиазапросы и стили видимого фокуса.

Полученная страница является основой для дальнейшего развития приложения. В следующих работах её можно дополнить работающим поиском, фильтрацией, рейтингами, отзывами, серверной частью и базой данных.
